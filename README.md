# StudyFlow

StudyFlow is a study task and deadline tracker for students. It helps students keep all their subjects and assignments in one place and never miss a deadline.

## Features

- User can add a new subject (name only)
- User can add a new task with a title and deadline date
- User can edit an existing task (title or deadline)
- User can delete a task
- User can mark a task as completed
- App shows a list of all tasks sorted by deadline
- App shows the closest upcoming deadlines on the home screen
- App saves all data locally, so tasks stay after closing the app

## How to run

1. Open the project in Android Studio.
2. Wait for Gradle sync to finish.
3. Click the Run button (▶) to build and launch the app on an emulator or connected device.
